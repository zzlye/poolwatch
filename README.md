# 号池监控

## 简介

号池监控用于集中查看不同渠道的余额、额度和账号状态。余额不足、账号异常或渠道无法访问时，可及时向已启用通知的电脑和手机发送提醒。

## 如何使用

1. 首次打开后，使用初始化口令创建管理员账号。
2. 登录后进入“渠道”，按向导填写渠道地址、登录信息、关注额度和提醒阈值。CLIProxyAPI 渠道填写管理密钥后即可读取账号状态；Sub2API 使用管理员账号，或补充 Admin API Key 后，也可查看号池。
   如果 New API 或 Sub2API 渠道只支持 GitHub、Linux.do 等网页登录，可选择“网页授权”；电脑端安装浏览器助手后可一键读取刚填写地址的登录状态，安卓应用会打开独立登录窗口。
3. 测试连接成功后保存渠道，随后可在“总览”查看最新状态。
4. 如需监控分组倍率，打开对应的 New API 或 Sub2API 渠道详情，自动检测并勾选需要关注的分组；随后可在“倍率”中展开渠道，查看已选分组和模型价格。
   如需单独监控模型价格，进入“模型价格”，选择已有渠道并自动检测分组，勾选模型后保存。价格监控与倍率监控可以同时使用，也可分别取消。
5. 在“推送设备”中允许通知，并发送测试通知确认电脑或手机能够收到提醒。
6. 如需通过邮箱接收提醒，可在“系统设置”的“邮件提醒”中选择邮箱服务商，填写发件邮箱、授权码和收件邮箱，再发送测试邮件。
7. 需要补充余额时，点击渠道上的“充值”前往该渠道的充值页面。
8. 安卓手机可从项目发布页面下载最新安装包，安装后登录并开启“持续监控”。

## 功能介绍

- 集中查看 New API、Sub2API、chatgpt2api、CLIProxyAPI 和自定义渠道。
- 支持 New API 与 Sub2API 的 GitHub、Linux.do 等网页登录方式。
- 电脑端可一键读取 New API 与 Sub2API 向导当前填写地址的登录状态，不扫描其他渠道。
- 自动读取 New API 与 Sub2API 当前账号可用的分组及实际计费倍率，可自由选择需要关注的分组，在倍率变化时发送提醒，并查看各模型的输入、输出、缓存、图片、按次及阶梯价格。
- 分别设置钱包余额、订阅额度、图片生成次数和账号状态的提醒阈值，每项都可单独关闭提醒并继续查看数值。
- 独立选择需要关注的模型价格，价格或计价单位变化时提醒，查看新旧价格和涨跌；首次保存不提醒，相同价格不重复提醒。
- 查看渠道当前状态、历史变化、异常记录和恢复情况。
- 查看 chatgpt2api 中经过隐藏处理的账号状态和剩余额度。
- 查看 CLIProxyAPI 中经过隐藏处理的账号提供商、可用状态、每账号额度、重置时间、订阅到期时间和请求统计。
- 查看 Sub2API 中经过隐藏处理的账号平台、类型、可用状态、内部额度和被动采样额度。
- 在电脑与安卓手机上接收余额不足、登录失效和渠道异常通知。
- 可使用自己的 QQ、163、Gmail 或 Outlook 邮箱，向一个或多个收件邮箱发送告警与恢复提醒。
- 安卓应用支持持续监控、断线补查、开机恢复、测试通知和后台运行设置引导。
- 自定义渠道名称、检查频率、充值页面和通知设备。
