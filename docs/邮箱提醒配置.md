# 邮箱提醒配置

## 使用前准备

号池监控可以使用你自己的邮箱发送告警与恢复提醒，不需要购买额外的通知服务。建议准备一个专门用于发送提醒的邮箱，并先在邮箱服务商的安全设置中开启两步验证或客户端发信功能。

配置时不要填写邮箱网页登录密码。请按服务商说明获取授权码或应用密码，并将它填写到“SMTP 授权码或应用密码”一栏。

## QQ 邮箱

1. 登录 QQ 邮箱网页版，打开“设置 → 账号”。
2. 找到“POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务”区域。
3. 开启 SMTP 相关服务，并按页面提示验证身份。
4. 生成授权码并立即保存；授权码通常只显示一次。
5. 在号池监控中选择“QQ 邮箱”，填写完整 QQ 邮箱地址和刚生成的授权码。

如果 QQ 邮箱设置页面的名称或入口发生变化，可在设置中搜索“授权码”或“SMTP”。

## 163 邮箱

1. 登录 163 邮箱网页版，进入“设置”中的客户端授权或邮箱客户端设置。
2. 开启 SMTP 相关服务，并按页面提示完成手机验证。
3. 设置或生成客户端授权码并妥善保存。
4. 在号池监控中选择“163 邮箱”，填写完整 163 邮箱地址和客户端授权码。

授权码与邮箱网页登录密码不同；邮箱安全设置发生变化后，旧授权码可能需要重新生成。

## Gmail

1. 登录 Google 账号，打开“管理您的 Google 账号 → 安全性”。
2. 先开启“两步验证”。
3. 在安全设置中打开“应用密码”，为号池监控生成一个新的应用密码。
4. 复制页面显示的应用密码；填写时可以去掉空格。
5. 在号池监控中选择“Gmail”，填写完整 Gmail 地址和应用密码。

部分单位、学校或受管理账号不会显示“应用密码”。此时需要由账号管理员允许该功能，或换用支持应用密码的发件邮箱。

## Outlook

1. 登录 Microsoft 账号，打开账号的“安全”设置。
2. 开启两步验证。
3. 如果安全设置提供“应用密码”，创建一个新的应用密码并保存。
4. 确认该邮箱允许邮箱客户端发送邮件；单位或学校账号可能需要管理员开启相应权限。
5. 在号池监控中选择“Outlook”，填写完整 Outlook 邮箱地址，并优先填写应用密码。

部分 Microsoft 账号已关闭传统的邮箱密码登录方式，且不会提供应用密码。遇到登录方式被服务商拦截时，可使用 QQ、163、Gmail 或其他允许客户端发信的邮箱。

## 在号池监控中填写

1. 登录号池监控，进入“系统设置”。
2. 找到“邮件提醒”，勾选“启用邮件提醒”。
3. 选择邮箱服务商，系统会自动填写对应的服务器地址、端口和连接安全方式。
4. 填写发件邮箱账号、授权码或应用密码。
5. 确认发件邮箱地址；“发件人名称”可填写“号池监控”。
6. 填写一个或多个收件邮箱。每行填写一个，也可以使用逗号或分号分隔。
7. 点击“发送测试邮件”。收到测试邮件后，再点击“保存邮件设置”。

测试邮件使用当前页面填写的内容，因此可以先验证再保存。已经保存过授权码时，授权码输入框留空会继续使用原来的授权码。

更换邮箱服务商、发件服务器或发件账号后，需要填写与新账号匹配的授权码或应用密码。如需彻底停用并删除已保存的授权码，点击“清除邮件设置”并确认。

## 测试与排查

1. 点击“发送测试邮件”后，先检查收件箱，再检查垃圾邮件或广告邮件目录。
2. 提示账号或密码错误时，确认填写的是授权码或应用密码，而不是网页登录密码。
3. 提示连接失败时，确认服务器可以访问外网，并检查邮箱服务商是否限制了当前登录地区或服务器地址。
4. 提示发信权限未开启时，回到邮箱安全设置，确认 SMTP 或邮箱客户端发信功能已经开启。
5. 多次失败后，可撤销旧授权码并重新生成，再回到号池监控重新测试。
6. 测试成功后，可触发一次测试告警或等待真实告警，确认告警邮件与恢复邮件都能送达。

授权码和应用密码应当像账号密码一样妥善保管，不要发送给他人，也不要写入截图、公开文档或问题反馈中。
