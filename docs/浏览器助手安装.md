# 号池监控浏览器助手安装

浏览器助手用于从 Chrome 或 Edge 已经登录的 New API 或 Sub2API 站点读取登录状态，随后自动填入号池监控。每次只读取渠道向导第一步填写的那个地址，不扫描其他站点。安装一次后，新增或更新渠道时可以直接点击“一键读取当前地址”。

## 安装

1. 在 New API 或 Sub2API 渠道的“网页登录”区域点击“下载浏览器助手”。
2. 解压下载的压缩包，保留解压后的整个文件夹。
3. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
4. 开启页面中的“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择刚才解压出的文件夹。
6. 刷新号池监控页面，页面显示“浏览器助手已连接”即表示安装完成。

已经安装旧版时，请下载 1.2.0 版本并覆盖原文件夹，然后在扩展程序页面点击“重新加载”。

## 一键读取

1. 先在浏览器中登录需要监控的 New API 或 Sub2API 站点。
2. 回到号池监控的渠道向导，选择“网页授权”。
3. 点击“一键读取当前地址”。
4. 页面显示读取成功后继续设置阈值并保存渠道。

如果当前填写地址尚未登录，浏览器助手会打开该地址。完成登录后回到号池监控，再点击一次“一键读取当前地址”。如果页面已登录，但新版站点的旧式会话接口仍未授权，助手会提示改用管理访问令牌，不再反复打开登录页。

## 站点开启浏览器验证后恢复监控

New API 站点开启 Turnstile 后，密码自动登录可能要求网页验证。这不等于账号已经失效。

1. 打开对应渠道详情，点击“网页登录恢复检测”。页面直接进入该渠道的网页授权步骤，保留名称、地址、检测间隔和阈值。
2. 电脑端打开渠道登录页，正常登录并完成站点要求的验证；回到号池监控，使用浏览器助手“一键读取当前地址”。安卓端使用授权窗口完成登录。
3. 新版站点请在站点设置的“安全与访问”生成管理访问令牌。在号池监控中切换到“访问令牌”，粘贴令牌；用户 ID 先留空。旧版站点如果连接测试提示需要用户编号，再填写用户 ID。模型调用使用的 API Key 不等于管理访问令牌；不要为监控自动重置已有令牌。
4. 完成连接测试后再保存。恢复流程不会提前覆盖原凭据；更改登录信息后需要重新测试。

保存后的有效会话或令牌可以用于后台查询余额，监控不重复发送密码登录请求。会话失效、被撤销或站点另外限制服务器访问时，需要重新授权或联系站点处理。浏览器验证由用户在站点页面完成，不会保存或重放 Turnstile 验证码。

## 自定义号池监控地址

浏览器助手默认信任 `https://jiance.zzlye.xyz`、本机默认地址以及本机 `8080` 端口。使用其他域名或端口时，在扩展程序详情中打开“扩展程序选项”，每行填写一个号池监控地址，然后刷新号池监控页面。公网号池监控地址必须使用 HTTPS，第一行地址会作为点击助手图标时默认打开的页面。
